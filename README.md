## 3つのエージェント

### 1. Job Agent（求人票 ＋ クライアントCRM）
既存スプレッドを土台に維持しつつ、**Job Agent 側で1か所更新するだけで、スプレッドと求人サイト掲載ページに同時反映**。二重管理をゼロに。
- 位置づけ: 単発の求人票ツールではなく、**クライアント（病院）情報を束ねる中核 CRM**。求人はクライアントにぶら下がる構造。
- 詳細画面は「クライアント情報・タスク・メモ・求人情報」の4枠に統合。求人情報カード内には**求人サイトでの見え方プレビュー**も内蔵。
- 参考モデル：人材特化 CRM「PORTERS」。将来像は「ほくジョブ版 PORTERS」＝どの拠点でもすぐ立ち上げできる土台。

### 2. Résumé Agent（履歴書 ＋ 職務経歴書）
LINE・メールで届く Excel／Word をまとめてドロップ → AI が氏名・経歴・免許資格・志望動機を自動構造化 → **JIS-A4 履歴書と職務経歴書を同時組み上げ**。校正4点（誤字・志望動機ズレ・空欄・個人情報）まで自動。
- 主役機能: 志望動機の**軸提案 → 担当者が軸を選択 → AI が書き直し提案**。応募先ごとに出し分け。
- 「決めるのは人、形にするのは AI」。数時間の往復が数分に。

### 3. Social Agent（SNS 自動運用）
月間カレンダーで投稿枠を一元管理 → AI が過去傾向から複数案を提案 → **カルーセル4枚のたたき台を生成** → デザインシステム風ノーコード UI で色・フォント・文字を編集 → Instagram に自動予約。
- 週1 → 毎日へ。集客費ゼロで年40名の実績を、毎日投稿で加速。

## セキュリティ設計

「どこに置くか」と「どう動かすか」の両面。

- **Context Harness（データの置き場所）** — 御社専用 VPS に MCP として構築。社内の許可された人だけがアクセス、外部からは絶対に触れられない隔離環境。
- **Claude Code Harness（AI の動かし方）** — 「計画 → 実行 → レビュー」の決まった手順でのみ稼働。承認範囲だけを実行、権限と操作ログを統制。
